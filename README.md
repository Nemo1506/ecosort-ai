**EcoSort AI** is an enterprise-grade computer vision platform and circular economy intelligence system engineered for automated municipal and commercial waste segregation. Built and spearheaded by **[Nemaan (Shaikh Nemaan)](https://github.com/Nemo1506)**, the platform integrates **MobileNetV2 transfer learning**, **Explainable AI (Grad-CAM)**, and a **cyberpunk-emerald glassmorphic Streamlit interface** to bridge real-time neural vision with localized municipal recycling regulations across the globe.

## 🌟 What EcoSort AI Delivers

### 1. 🧠 Explainable AI (Grad-CAM Neural Attention Heatmaps)
* **Spatial Feature Transparency**: Computes gradient-weighted class activations on the final convolutional bottleneck of MobileNetV2 (`features[-1]`).
* **Visual Heatmap Overlay**: Generates a high-contrast thermal attention map overlaid onto item photographs, revealing the exact edges, caps, ridges, or textures the neural network used to reach its classification decision.

### 2. 🌐 Global Municipal Jurisdiction Selector
* **Multi-Country Bin Standards**: Segregation rules adapt dynamically across 5 major global jurisdictions:
  * 🇺🇸 **United States (Single-Stream Standard)**: Blue (Recycle), Green (Compost), Black/Gray (Trash), Red (Hazardous).
  * 🇪🇺 **European Union (Dual System / Green Dot & Pfand)**: Yellow (Packaging/Pfand), Blue (Paper), Brown (Bio), Green/White (Glass banks).
  * 🇬🇧 **United Kingdom (Council Recycling Protocol)**: Mixed dry wheelies, food caddies, and HWRC drop-off depots.
  * 🇯🇵 **Japan (Strict Multi-Stream Resource Segregation)**: Moeru (burnable), Moenai (non-burnable), Pura (plastics), and tied Danbōru (cardboard).
  * 🇮🇳 **India (Swachh Bharat Urban Solid Waste Rules)**: Green (Wet/Gila), Blue (Dry/Sookha), and Red (Domestic Hazardous).
* **Live Regulation Swapping**: Switching jurisdictions immediately recalculates designated bin names, bin colors, and local handling rules.

### 3. 💬 EcoSort Intelligent Material Assistant (Natural Language Chatbot)
* **Complex Material Knowledge Base**: Specialized retrieval engine addressing 30+ notoriously ambiguous items that consumer apps struggle with:
  * Greasy pizza boxes (tearing clean lids vs compost bottoms)
  * Takeaway coffee cups (hidden polyethylene linings)
  * Swollen or used lithium batteries (fire hazards & terminal taping)
  * Thermal store checkout receipts (toxic BPA/BPS endocrine disruptors)
  * Aerosol spray cans, blister packs, lightbulbs, mirrors, Pyrex, and PLA bioplastics
* **Prompt Chips**: Instant one-click query suggestions for common household dilemmas.

### 4. 🔊 Smart-Bin Voice Audio & IoT Kiosk Mode
* **Accessibility & Kiosk Experience**: Integrated browser-native **Web Audio API** and **Web Speech Synthesis**.
* **Futuristic Sorting Chime**: Plays a dual-tone crystal chime on classification and verbally announces: *"Item classified as [Material]. Deposit into [Designated Bin]."*, simulating a physical smart bin kiosk.

### 5. ⚖️ Life-Cycle Assessment (LCA) A/B Material Comparison Studio
* **Cradle-to-Grave Ecological Benchmarking**: Compare any two packaging materials side by side.
* **Quantified Environmental Metrics**:
  * ⏳ Landfill Degradation Lifespan (e.g. 450 years for PET vs 2 months for cardboard)
  * ⚡ Embodied Energy Intensity ($\text{MJ/kg}$)
  * 🔄 Circular Recycling Fidelity (% quality preserved across cycles)
  * ☣️ Environmental Toxicity Hazard Score (1 to 10)
  * 🏆 Dynamic Carbon Efficiency Winner Verdict badge

### 6. 📦 High-Volume Multi-Item Batch Auditor
* **Industrial Batch Audits**: Upload up to 10 waste photos simultaneously.
* **Batch Analytics Manifest**: Computes total items audited, diversion recyclability rate (%), hazardous item count, total batch latency, and per-item classification cards.
* **Exportable Manifest**: Download comprehensive JSON audit records for municipal fleet tracking.

### 7. 🖨️ Printable Formal ESG Waste Audit Certificate
* **Official Corporate Compliance**: Generates a self-contained, printable HTML/PDF audit certificate.
* **Cryptographic Verification**: Includes an SHA-256 derived audit ID (e.g. `ECO-F89A-4B2D-91E3`), timestamp, official seal, inspector badge, and print media CSS.

### 8. 🌍 Enterprise ESG Environmental Impact Simulator
* **Multi-Scale Scope Presets**:
  * 👤 Single Household
  * 🏢 Apartment Complex (50 Units)
  * 🏬 Corporate Office (200 Staff)
  * 🏙️ Municipal Ward (2,000 Homes)
* **Ecological Dividends**: Computes landfill mass diverted ($\text{kg}$), $\text{CO}_2\text{e}$ prevented ($\text{kg}$), grid energy conserved ($\text{kWh}$), smartphone recharges equivalent, car emissions avoided ($\text{km}$), groundwater heavy metal protection, and dynamic Eco-Champion Rank tiers.

### 9. 🗜️ Direct Dataset `.zip` Ingestion & Stratified Splitter
* **Drag-and-Drop Archive Ingestion**: Upload dataset `.zip` files directly in the UI.
* **Auto-Detection**: Automatically detects existing Kaggle downloads (`archive(1).zip`, `archive.zip`) for 1-click unpacking.
* **Automated Stratified Splitter**: Deterministic 70% Train, 15% Validation, 15% Test partition across 15,515 images.

## 🛠️ Errors Checked & Resolved

1. **Windows 11 Smart App Control (SAC) Hardening**:
   * *Issue:* Windows 11 SAC (`VerifiedAndReputablePolicyState: 1`) blocked newly compiled unsigned `.pyd` C-extensions in Python 3.13 packages (`tensorflow._pywrap_tf2.pyd`, `pandas._libs.index.pyd`, `sklearn._cython_blas.pyd`) with NTSTATUS `0xc0e90002`.
   * *Resolution by Nemaan:* Re-architected data ingestion, splitting, training, evaluation, and metrics using **pure Python**, **PyTorch** (digitally signed by Microsoft/PyTorch publishers), and **NumPy**. Zero DLL blocks.
2. **Streamlit Deprecation Warnings**:
   * *Issue:* `use_container_width=True` deprecated in Streamlit 1.65+.
   * *Resolution:* Fully migrated to `width="stretch"` across all image components.
3. **Matplotlib Font Glyph Warnings**:
   * *Issue:* Unicode emojis in Matplotlib bar charts triggered `UserWarning: Glyph missing from font DejaVu Sans`.
   * *Resolution:* Separated clean text typography for Matplotlib rendering from emoji-enhanced UI elements.

## ⚡ Quick Start Guide

### 1. Environment Setup

```bash
# Clone or navigate to the repository
cd ecosort-ai

# Create and activate virtual environment
python -m venv .venv

# Windows (PowerShell):
.\.venv\Scripts\Activate.ps1
# Windows (CMD):
.\.venv\Scripts\activate.bat
# Linux/macOS:
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Dataset Extraction & Splitting

If you have `archive(1).zip` or any Kaggle dataset zip:

```bash
# Auto-detect archive from Downloads folder and extract to data/raw/
python src/download_dataset.py

# Or extract from a specific zip file
python src/download_dataset.py --from-zip "path/to/archive.zip"

# Execute deterministic 70/15/15 stratified split
python src/prepare_data.py
```
*(Alternatively, drag-and-drop the `.zip` directly inside Tab 2 of the Web UI!)*

### 3. Model Training & Evaluation

```bash
# Fast demonstration training (3 epochs):
python src/train.py --quick --epochs 3

# Full production transfer learning (5 epochs):
python src/train.py --epochs 5

# Evaluate model on the 2,325 held-out test images:
python src/evaluate.py
```

### 4. Launch the Enterprise Platform

```bash
streamlit run app.py
```

Open your browser to:
👉 **`http://localhost:8501`**
